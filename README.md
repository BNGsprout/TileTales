This is a game I created while following a C#/Unity course. It turned out to be pretty good, so I started working on it more.
		
This project uses the Unity game engine. The controls are all in the project. Supports keyboard and controller.
Might be put out on Steam for free if I ever buy the assets instead of using a free tutorial licence.
	
Feel free to do what you like with this project as long as you don't sell it as your own work.
	
This game uses Unity 6.5, so make sure to install that before attempting to open this project. There are some minor bugs that may or may not have been purposefully set there (bad guys not dying when shot in the back, crazy things happening when bouncing too fast). Just think of it as a unique challenge to overcome.
	
Suggestions would be appreciated.
